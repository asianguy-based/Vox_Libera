## 📥 How to Log New Feedback

1. Add a new row to the table below as soon as feedback comes in (don't batch — easy to forget details later).
2. Fill in **Status** as `New` initially.
3. Move to `In Progress` when you start acting on it, `Resolved` when done, or `Won't Fix / Declined` with a one-line reason if you decide not to act on it.
4. If it results in a code change, note the version number it shipped in (see version log on the main project page).
